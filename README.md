# 📊 Retail Sales Performance Analysis

A Python-based Data Analytics project that analyzes retail sales data to generate valuable business insights. This project helps understand sales trends, product performance, regional performance, and revenue generation through data visualization and statistical analysis.

---

## 👨‍💻 Developed By

**Harshit Singh**

## 📌 Project Overview

Retail businesses generate large amounts of sales data every day. This project processes retail sales records and transforms raw data into meaningful insights.

Using Python and data visualization libraries, the system helps identify:

- Top-selling products
- Best-performing regions
- Monthly sales trends
- Revenue distribution
- Profit analysis
- Business growth opportunities

---

## 🎯 Objectives

- Analyze retail sales performance.
- Identify top-performing products.
- Compare sales across different regions.
- Generate visual reports and dashboards.
- Support data-driven business decisions.

## 📂 Dataset Information

The dataset contains retail sales records with the following attributes:

| Column Name | Description |
|-------------|-------------|
| Order ID | Unique order number |
| Date | Transaction date |
| Product | Product name |
| Category | Product category |
| Region | Sales region |
| Quantity | Units sold |
| Unit Price | Price per unit |
| Revenue | Total sales amount |
| Cost | Product cost |
| Profit | Revenue - Cost |

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/your-username/Retail-Sales-Performance-Analysis.git
```

### Move to Project Directory

```bash
cd Retail-Sales-Performance-Analysis
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Project

```bash
python retail_sales_analysis.py
```
